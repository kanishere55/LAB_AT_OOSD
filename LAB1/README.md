# LAB1 - Lập trình hướng đối tượng

## Mô tả

Bài LAB1 môn Phương pháp phát triển phần mềm hướng đối tượng.

Bài thực hành xây dựng các lớp hình học theo hướng đối tượng bằng Java, sử dụng lớp trừu tượng, kế thừa và ghi đè phương thức.

## Nội dung

### Lap01

Mã nguồn Java của bài thực hành:

* `CHinhVe.java`: lớp trừu tượng dùng làm lớp cơ sở cho các hình vẽ.
* `CDiem.java`: biểu diễn điểm.
* `CTamGiac.java`: biểu diễn tam giác.
* `CTuGiac.java`: biểu diễn tứ giác.
* `CEllipse.java`: biểu diễn hình ellipse.
* `Main.java`: chương trình chính dùng để chạy và kiểm tra các lớp.
