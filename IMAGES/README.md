## Mở và đối chiếu sơ đồ

1. Mở [diagrams.net](https://app.diagrams.net/) hoặc ứng dụng draw.io trên máy. Chọn **File → Open from → Device** và chọn file `.drawio`.
2. Nếu đang xem file trên GitHub, chọn **Raw** hoặc **Download raw file** để tải file nguồn rồi mở trong diagrams.net.
3. Dùng bảng của từng LAB bên dưới để tìm file nguồn tương ứng với hình trong báo cáo Word.

Các số hình giữ theo từng báo cáo riêng. Khi ghép báo cáo tổng hợp, đối chiếu theo cả tên LAB và tên hình. Hình P.6 của LAB5 gồm hai biểu đồ trạng thái; mỗi biểu đồ được lưu thành một file nguồn riêng. Bài tập tổng hợp của LAB4 có báo cáo riêng và được liệt kê cùng LAB4.

Thư mục này lưu file nguồn, không dùng PNG, JPG, SVG hoặc PDF thay cho file `.drawio`. Ảnh sơ đồ và ảnh chụp kết quả trong báo cáo Word phục vụ việc đọc báo cáo.
