# LAB2 - Hệ thống quản lý thư viện

## Mô tả
Xây dựng hệ thống quản lý thư viện bằng C# Windows Forms và SQL Server.

## Chức năng
- Quản lý nhân viên
- Quản lý thể loại
- Quản lý nhà xuất bản
- Quản lý đầu sách
- Quản lý độc giả và thẻ thư viện
- Quản lý mượn - trả sách
- Quản lý phí phạt
- Thống kê

## Công nghệ sử dụng
- C#
- Windows Forms
- .NET Framework 4.7.2
- SQL Server
- ADO.NET
