# Mô hình UML LAB6

Có **8 file draw.io riêng**, mỗi file chỉ chứa **một sơ đồ trên một trang A4 dọc**. Hình, chữ và đường nối đều có thể chỉnh sửa; mở từng file bằng liên kết Draw.io trong bảng dưới.

Trong draw.io/diagrams.net, chọn **File → Open From → Device** rồi chọn file `.drawio`. Nhấp đúp để sửa chữ; các hình được nhóm để di chuyển cùng nội dung, có thể dùng **Arrange → Ungroup** khi cần chỉnh từng thành phần.
